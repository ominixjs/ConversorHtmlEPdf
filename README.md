Conversor de planilhas para PDF e HTML na extensão .csv. O programa gera arquivos em .html e .pdf ambos estruturados para imprimir dados no formato de tabela.

Ainda esta em desenvolvimento, muita coisa pode ser implementada. O projeto foi visado para aprendizado e aprimoramento.
